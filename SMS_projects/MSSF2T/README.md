# MSSF2T — Master Street Fighter 2 Turbo

Demake/port de Super Street Fighter II Turbo para Sega Master System.

- `art_src_base/` — sheets de referência (`reference_only`, Capcom). Não vão para a ROM.
- `res/` — tradução SMS-nativa (32×64, paleta 6-bit, palco 10 tiles).
- Engine: FSM numérica estilo HAMOOPIG (idle/walk/punch/kick/guard/special/hit/KO/rounds).

```
./build.sh
```

Gênero: `fighting`. Teto de claim: protótipo jogável. Não `ready_for_aaa`.
