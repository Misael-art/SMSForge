# 08-bible-artistica — hamoopig

Silhueta legível a 256×192, contraste alto, HUD em tile.
Personagens finais exigem model sheet e proveniência. A silhueta 16×32 atual
é **probe técnico**, não entrega visual.

Paleta 6-bit. Índice 0 transparente. P1 quente (laranja), P2 frio (ciano).
Ken comercial não é fonte de pixel. Musgo/Ryo da origem só entram após
reautoria SMS e gate de licença.
