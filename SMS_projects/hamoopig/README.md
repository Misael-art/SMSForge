# HAMOOPIG SMS

Portabilidade da engine de luta HAMOOPIG (Mega Drive / SGDK) para Sega Master System
no SMSForge. Reimplementação de comportamento; não é cópia de API SGDK.

Origem (somente leitura): projeto HAMOOPIG no workspace Sgdk Forge.
Pesquisa local: `import/hamoopig_md/` + `import/inventory.json`.

```
./build.sh
./run.sh
```

Gênero: `fighting`. Teto: protótipo jogável. `ready_for_aaa` false.
Créditos da engine original: GameDevBoss (Daniel Moura) — HAMOOPIG is free.
